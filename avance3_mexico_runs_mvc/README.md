# Mexico Runs - Avance 3

Maqueta codificada de la pantalla principal del sistema web de renta de vehiculos
Mexico Runs. La estructura separa responsabilidades en Modelo, Vista y
Controlador usando JavaScript.

## Estructura MVC

- `app/models/vehicleModel.js`: datos de vehiculos y funciones de consulta.
- `app/views/homeView.js`: renderizado del catalogo y de la cotizacion.
- `app/controllers/homeController.js`: eventos, filtros y calculo de reserva.
- `public/css/styles.css`: estilos visuales de la maqueta.
- `public/img/`: imagenes locales usadas por la pantalla.
- `index.html`: estructura principal de la pantalla de inicio.

## Como abrir

Abre `index.html` en un navegador moderno. No requiere instalacion de
dependencias ni conexion a Internet.

## Funciones incluidas

- Pantalla principal del sistema.
- Barra de navegacion con secciones del mapa del sitio.
- Buscador de ciudad y fechas.
- Catalogo de vehiculos.
- Filtros por tipo de vehiculo.
- Cotizacion rapida con costo estimado.
- Acceso visual para administracion.
